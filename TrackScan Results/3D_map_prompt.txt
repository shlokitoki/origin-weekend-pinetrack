WHAT TRACKSCAN IS
Phones lying on the floor of LA Metro E Line trains record vibration + GPS. We rode 5 trains (11 phones) between Expo Park/USC and Culver City, removed braking/accelerating seconds, and found stretches of track that shake hard on every ride. The page lets an inspector see the line in 3D, find each rough spot, and see the evidence for it.

TECH (keep it simple and reliable)
- One index.html with inline CSS and JS, plus a data/ folder holding my files. No build step, no API keys. It must run on Replit (static site) and locally via `python3 -m http.server`.
- MapLibre GL JS v4 from a CDN (unpkg or jsdelivr).
- Base map style: OpenFreeMap positron, https://tiles.openfreemap.org/styles/positron (vector source "openmaptiles").
- Aerial imagery: raster source with tiles https://basemap.nationalmap.gov/arcgis/rest/services/USGSImageryOnly/MapServer/tile/{z}/{y}/{x}, tileSize 256, maxzoom 16 (let MapLibre overzoom), inserted below the building and label layers. On by default, toggled by an "Aerial detail" button.
- 3D buildings: fill-extrusion layer from source "openmaptiles", source-layer "building", height ["get","render_height"], base ["get","render_min_height"], color #ece9e2, opacity 0.9, minzoom 14. "Buildings on/off" toggle.
- Attribution, bottom-right: "© OpenStreetMap contributors · OpenFreeMap © OpenMapTiles · USDA, USGS The National Map: Orthoimagery".

DATA FILES (put in data/)
- eline_route.geojson: two LineStrings. id "full_line" = whole E Line (draw as a thin dashed gray line); id "scanned" = the 9.6 km we measured (draw as a 3 px dark line under the ribbon).
- track_ribbon.geojson: 369 polygons, each an 8 m-wide, 25 m-long slice of the track, with properties median_score (1 = typical track; higher = rougher; range ~0.5–3.4), hot_fraction, recordings, rides_rough, rides_covering, start_m, end_m.
- track_roughness.geojson: the same 25 m slices as LineStrings (use for hover tooltips if easier).
- hotspots.geojson (from our R pipeline): for each hotspot, one Point (id "H-01"…, rank, severity, rides_rough, rides_covering, both_directions, between, cross_street (may be null), nearest_station, dist_to_station_m, start_m, end_m, length_m, google_maps, label, status) and one LineString with id "H-01-zone" etc. marking its extent.
- stations.geojson: Points with name, chainage_m, in_scanned_segment.
- summary.json: headline numbers (km_scanned, rides, recordings, moving_seconds, cruise_seconds, phase_share, chance_test, rides[]).

THE 3D "SHAKE RIBBON" (the hero visual)
- Draw track_ribbon.geojson as a fill-extrusion standing on the track, so the vibration profile literally rises out of the ground: height = 1 m for median_score <= 1, otherwise 1 + 8 × (median_score − 1) metres, capped at 22 m.
- Color on ONE hue, light to dark: <= 1.2 → #d8d4cc (neutral), 1.5 → #efb3ac, 2.0 → #e07a72, 2.5 → #c9463f, >= 3.0 → #8e1f1f (interpolate). Opacity 0.95.
- Hover a slice → small tooltip: "25 m slice · 2.4× typical shake · rough on 4/5 rides".
- Hotspot zones (the "-zone" LineStrings): a 5 px line in #8e1f1f on top, with a soft glow (second, wider line at low opacity).
